# hospital_readmission
Hospital readmission is an important indicator of patient outcomes and healthcare quality. This project investigates clinical and operational factors associated with hospital readmission among diabetic patients and develops predictive models for identifying encounters associated with readmission within 30 days.

# Data source
Diabetes 130-US Hospitals for Years 1999–2008 — UCI Machine Learning Repository
https://archive.ics.uci.edu/dataset/296/diabetes-130-us-hospitals-for-years-1999-2008
